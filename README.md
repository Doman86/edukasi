# Web Edukasi 📚

Aplikasi berbasis Laravel untuk membantu guru dalam membuat dan mengelola soal secara lebih cepat dan efisien.

---

## 🎯 Tujuan Project

Project ini dibuat untuk:
- Membantu guru membuat soal dengan mudah
- Menghemat waktu dalam penyusunan soal
- Mengurangi kerja manual

---

## ⚙️ Fitur Utama

- ✏️ Generate soal otomatis (AI)
- 📋 Manajemen soal (tambah, edit, hapus)
- 📤 Export soal
- 👨‍🏫 Khusus untuk guru

---

## 🛠️ Teknologi yang Digunakan

- Laravel
- PHP
- MySQL
- Bootstrap / Tailwind (opsional)
